# 📍 Offline Name Tag (오프라인 네임택)

> 스토어 진열용 네임택(모델명 · 판매가)을 등록하고, A4 용지로 출력하는 방법을 안내합니다.
>
> 경로 : <span className="path-badge">IIC BO > 스토어 운영 관리 > 오프라인 네임택</span>

<div className="blockquote-mint">

> <mark>**한국은 어티슈(ATIISSU, 브랜드 코드 `1600`) 네임택만 출력합니다.**</mark><br/>
> 어티슈 네임택은 QR 코드를 사용하지 않으니, 출력 전 <mark>**제품 QR 포함**</mark> 체크를 해제해 주세요.

</div>

## 👉 네임택 출력 순서

> **네임택 등록** → **상품 선택** → **추가 메모 & 수량 입력** → **미리보기** → **출력 & 저장**

| Step | 처리 내용 |
|:---:|---|
| **1** | **네임택 등록** 클릭 → **개별 출력** 또는 **업로드 출력** 선택 |
| **2** | 브랜드 → BP(법인) → 스토어 선택 후 출력할 모델 선택 |
| **3** | 모델별 렌즈 가능 여부, 출력 수량 입력 |
| **4** | 미리보기 확인 후 **출력 & 저장** → 등록 내역 저장 + 인쇄 |

## 5. 네임택 등록 — 업로드 출력

출력할 모델이 많은 경우 엑셀 파일로 한 번에 등록합니다.

| Step | 처리 내용 |
|:---:|---|
| **1** | **네임택 등록** → **업로드 출력** 탭에서 **업로드 템플릿 다운로드** 클릭 → 양식(`NameTag_upload_form.xlsx`) 다운로드 |
| **2** | 양식에 맞춰 작성 |
| **3** | 작성한 파일(.xlsx / .xls, 최대 5MB)을 끌어다 놓거나 선택한 뒤 **등록** 클릭 |
| **4** | 등록 완료 후 열리는 미리보기에서 **제품 QR 포함** 해제 후 출력 |

### 📝 양식 작성 방법

| 컬럼 | 필수 여부 | 입력 내용 |
|---|:---:|---|
| **Brand Code** | **필수** | 브랜드 코드 (어티슈 `1600`) |
| **Store Code** | **필수** | 스토어 코드 |
| **Product Code** | **필수** | <mark>**제품 코드(SKU)**</mark> — 모델 코드가 아님 |
| **Additional Note** | — | <mark>**사용하지 않음**</mark> (비워 두기) |
| **Prescription** | **필수** | 렌즈 가능 여부 `Y` / `N` |
| **Qty** | **필수** | 출력 수량 (1 ~ 10) |

- 한 파일에는 **브랜드 1개 · 스토어 1개**만 입력할 수 있습니다.
- 출력 수량은 1 ~ 10개만 입력할 수 있으며, 10개를 넘으면 오류가 발생합니다.
- 파일 전체 출력 수량은 500개 이하여야 합니다.

<div className="blockquote-warning">

> <mark>**한 행이라도 오류가 있으면 파일 전체가 등록되지 않습니다.**</mark><br/>
> 오류 목록에서 해당 행을 확인해 수정한 뒤 다시 업로드해 주세요.

</div>

## ❓ FAQ

> **Q. 출력할 제품이 목록에 없어요.**
>
> A. 오늘 기준 <u>유효한 판매가</u>가 없는 제품은 표시되지 않습니다. 패키지와 렌즈도 목록에서 제외됩니다.

> **Q. 네임택에 QR 코드가 같이 출력됐어요.**
>
> A. 미리보기에서 <u>제품 QR 포함</u> 체크를 해제하지 않은 경우입니다. 출력 내역 상세에서 재출력하면서 체크를 해제해 주세요.

> **Q. 업로드 시 `엑셀의 브랜드 코드는 1개만 허용됩니다.` 오류가 나와요.**
>
> A. 한 파일에는 <u>브랜드 1개</u>만 입력할 수 있습니다. Brand Code를 모두 `1600`으로 맞춰 주세요.

> **Q. 저장 시 `Invalid name tag print price` 오류가 나와요.**
>
> A. 선택한 제품의 판매가가 바뀌었거나, 해당 스토어에서 판매하지 않는 제품입니다. 상품을 다시 선택해 주세요.

</div>
