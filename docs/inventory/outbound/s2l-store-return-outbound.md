# S2L 스토어 반품 출고

> S2L : Store To Logistics로, 스토어에서 물류센터로 반품하는 출고 유형을 의미합니다.
>
> 경로 : `Inventory > Outbound`

---

## 1. 출고 유형

| 유형 | 설명 | 출발지 → 도착지 | 운영 예시 |
|:---:|---|---|---|
| **C2C** | 법인 간 이동 | 법인 → 법인 | 법인 물류 입고 후, 본사 반품이 필요해 전산 상 '재고 차감(출고)'가 필요한 경우 |
| **S2S** | 스토어 간 이동 | 스토어 → 스토어 <span className="info-badge">같은 법인 내에서만 허용</span> | 전산 상 '스토어'로 설정된 구간에서 재고 이동이 필요한 경우 |
| **L2S** | 물류 → 스토어 | 물류 창고 → 스토어 <span className="info-badge">같은 법인 내에서만 허용</span> | 물류 재고를 스토어로 분배(출고)가 필요한 경우 |
| **S2L** | 스토어 → 물류 | 스토어 → 물류 창고 <span className="info-badge">같은 법인 내에서만 허용</span> | 스토어 재고를 물류로 회송이 필요한 경우 (e.g : 스토어 반품) |


---

## 2. 출고 등록

출고 등록 버튼 선택 시 모달이 표시되며, 아래 3가지 탭으로 구성되어 있습니다.

| 탭 | 설명 |
|:---:|---|
| **일반 출고** | 출고·입고 스토어 및 로케이션을 각각 지정한 뒤, 제품을 개별 선택하고 수량을 입력하여 출고 처리 |
| **법인 출고** | 출고 스토어만 선택하여 본사로 반품 처리하는 방식. 본사 대상이므로 별도 입고 스토어 설정 없이 출고만 반영 |
| **일괄 출고 등록** | 일반 출고 또는 법인 출고 건의 제품이 대량인 경우, 엑셀 파일로 작성하여 일괄 업로드로 처리 |

---

<details>
<summary>출고·입고 스토어 선택</summary>

출고 등록 시, 아래 순서로 출발지와 도착지를 선택합니다.

1. **출고** : 법인 → 스토어 → 로케이션
2. **입고** : 법인 → 스토어 → 로케이션

<div className="blockquote-gray">

> 각 드롭다운(법인 / 스토어 / 로케이션)에 조회되는 마스터 정보는 **계정에 설정된 권한**에 따라 다르게 표시됩니다.

</div>

</details>
