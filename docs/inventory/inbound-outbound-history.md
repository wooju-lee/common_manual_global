# Inventory In/Out History (입/출고 내역)

> 스토어 간 재고 이동이 **출고 요청 → 출고 → 입고 확정**까지 어떻게 진행되었는지 한 화면에서 확인하는 메뉴입니다.
>
> 경로 : <span className="path-badge">IIC BO > Inventory > Inventory In/Out History</span>

## 👉 언제 사용하나요?

- 스토어·물류 간 이동 건이 **입고 확정까지 완료되었는지** 확인할 때
- 이동 건의 **출고 수량과 입고 확정 수량**을 비교할 때

## 1. 조회

<div className="img-placeholder">📷 [Image] Inventory In/Out History 검색 및 목록 화면</div>

출발(**From Store Location**)과 도착(**To Store Location**) 스토어·로케이션을 선택하고, 기간 기준을 고른 뒤 **Search**를 클릭합니다.<br/>
기간 기준은 `Request Date`(출고 요청일) / `Confirmed Inbound Date`(입고 확정일) / `Registration Date`(등록일) 중에서 선택합니다.

## 2. 목록에서 확인할 수 있는 것

- **Outbound Request Qty**(출고 요청 수량), **Outbound Qty**(출고 수량), **Confirmed Inbound Qty**(입고 확정 수량)를 비교해 이동 진행 상황을 확인할 수 있습니다.
- **Created By**(요청·등록자)와 **Approved By**(승인자)로 처리한 계정을 확인할 수 있습니다.
