# 📍 Inventory In/Out History

> This menu shows how store-to-store stock transfers progressed — **outbound request → outbound → inbound confirmation** — on one screen.
>
> Path : <span className="path-badge">IIC BO > Inventory > Inventory In/Out History</span>

## 👉 When to use

- To check whether a store/logistics transfer has been **completed through inbound confirmation**
- To compare the **outbound quantity and confirmed inbound quantity** of a transfer

## 1. Search

<div className="img-placeholder">📷 [Image] Inventory In/Out History search and list screen</div>

Select the source (**From Store Location**) and destination (**To Store Location**) store/location, choose the period basis, then click **Search**.<br/>
Choose the period basis from `Request Date` (outbound request date) / `Confirmed Inbound Date` (inbound confirmation date) / `Registration Date` (registration date).

## 2. What you can see in the list

- Compare **Outbound Request Qty** (outbound request quantity), **Outbound Qty** (outbound quantity), and **Confirmed Inbound Qty** (confirmed inbound quantity) to check the progress of a transfer.
- Check the handling accounts in **Created By** (requester/registrant) and **Approved By** (approver).
